# Changelog

## v0.3.0 - 2026-02-17

- **UI:** Premium visual redesign with glassmorphism layout, improved typography, and modern spacing.
- **UX:** Added relationship summary area with kinship-first messaging.
- **Feature:** Introduced `resolveKinship` for friendlier labels (e.g. grandparent, aunt/uncle, in-law).
- **Feature:** Added `normalizeData` to support extensible person and relationship metadata.
- **Data:** Expanded sample `data.js` schema with fields like `display_name`, `nickname`, `subtype`, and `confidence`.
- **Test:** Updated Jest coverage for normalization + kinship resolver behavior.
- **Docs:** Refreshed README, PRD, and roadmap to reflect current project direction.
